# street-tools-releases

Public release channel for **Street Tools**.

This repository does not contain source code. It exists to host compiled builds, release notes, and a public place to report issues.

## Downloads

Grab the latest build from the [Releases page](https://github.com/quietcactus/street-tools-releases/releases/latest).

Each release includes:

- The packaged build for each supported platform
- Release notes describing new features, fixes, and known issues

Older versions remain available on the [full releases list](https://github.com/quietcactus/street-tools-releases/releases).

## Installing

1. Download the asset for your platform from the latest release.
2. Extract or run the installer.
3. Follow any version specific steps listed in that release's notes.

## Updating

Download the newest release and install it over your existing version. Check the release notes for any breaking changes before upgrading.

## Reporting issues

Found a bug or have a feature request? [Open an issue](https://github.com/quietcactus/street-tools-releases/issues/new) and include:

- The version you are running
- Your operating system
- Steps to reproduce the problem
- What you expected to happen versus what actually happened
